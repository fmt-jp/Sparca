# HANABI

Macromedia Fireworks に着想を得た、ブラウザで動くハイブリッド型（ベクター＋ラスター）グラフィックエディタです。
仕様は [`docs/spec.md`](docs/spec.md)、設計は [`docs/design.md`](docs/design.md) を参照してください。

旧称は Sparca です（2026-10-22 に HANABI へ改称）。仕様書 `docs/spec.md` は当時の名称のまま残しています。リポジトリ名・公開 URL・ソースコード内の識別子（`SparcaDocument` など）も Sparca のままです。

## 環境構築

- Node.js 22 以上、npm 10 以上

```sh
npm install
```

## 起動

```sh
npm run dev        # 開発サーバー（http://localhost:5173）
npm run build      # 本番ビルド（dist/）
npm run preview    # ビルド結果の確認
```

## 公開（GitHub Pages）

`main` ブランチに push すると `.github/workflows/deploy-pages.yml` が型チェック・単体テスト・ビルドを実行し、GitHub Pages に公開します（Actions タブから手動実行も可能）。
初回のみ、リポジトリの Settings → Pages → Build and deployment → Source を「GitHub Actions」に設定してください。
ビルドは相対パス（`base: './'`）なので、`https://<owner>.github.io/<repo>/` のようなサブパスでも動作します。

## テスト

```sh
npm test           # 単体テスト（Vitest）：モデル、履歴、保存形式、画像処理
npm run typecheck  # 型チェック
npm run test:e2e   # E2E テスト（Playwright + Chromium）。ビルドとプレビューサーバー起動を自動で行う
```

E2E は `@playwright/test` 1.56.1 に固定しています（クラウド環境にプリインストールされた Chromium と対応させるため）。
別環境では初回に `npx playwright install chromium` が必要です。

### 色の選択（パレット）

色の欄（塗り・線・文字色・グロー・影・背景色・グリッド色など）は色見本のボタン。押すと Fireworks 風のパレットが開く：上段に選択中の色・カラーコード入力（#RGB / #RRGGBB）・「なし」（赤斜線、塗り・線のみ）・その他の色、本体に基本色の列と Web セーフ 216 色。
色にマウスを乗せるとコードを表示し、クリックで決定（Undo 1回分）。欄外クリックか Esc で閉じる。
虹色の「その他の色」ボタンはアプリ内の色作成画面（彩度・明度の四角、色相バー、R/G/B・カラーコード入力、新旧の比較）を開く。**OK を押すまで色は適用されない**。キャンセルで色見本に戻る。

### エフェクト

プロパティパネル（下段）の「エフェクト」で、オブジェクト（図形・パス・テキスト・画像）に Fireworks のライブフィルターのような効果を**いくつでも**付けられる。効果は画素に焼き込まず、設定として保存されるので後から何度でも変更できる。

| 分類 | エフェクト | 主な設定 |
|---|---|---|
| シャドウとグロー | ドロップシャドウ、内側シャドウ | 色、不透明度、角度、距離、ぼかし |
| | グロー、内側グロー | 色、不透明度、ぼかし、広がり |
| ベベルとエンボス | 内側ベベル、外側ベベル（縁の色、角は丸く膨らむ）、エンボス（くぼませる／オブジェクトの色を表示） | 幅（初期値 10px）、柔らかさ（3px）、光の角度（左上）、明暗の強さ（75%）。Fireworks と同様、光源に向いた斜面を明るく、反対側を暗くする滑らかな陰影 |
| ぼかしとシャープ | ぼかし、ぼかし（ズーム）、シャープ | ぼかし量／量・中心 X・中心 Y（オブジェクトの枠に対する %）／量・半径 |
| 色の調整 | 明るさ・コントラスト、色相・彩度、トーンカーブ、グレースケール、セピア、反転、カラーオーバーレイ | 各値／カーブ／色（グレースケール・セピア・反転は「強さ」で効き具合を調整） |

- **追加**：「＋ 追加」から種類を選ぶ。同じ種類も複数付けられる（「ドロップシャドウ 1」「ドロップシャドウ 2」と番号が付く）。
- **適用順**：リストの**上から順に**適用され、各エフェクトは前のエフェクトまでの結果に対してかかる（例：カラーオーバーレイ→反転 と 反転→カラーオーバーレイ は結果が違う）。行の左端のつまみ（⠿）か名前をドラッグして並べ替える（移動先に青い線が出る。パネルの上下端では自動でスクロール。ドラッグ1回が Undo 1回分）。キーボードやボタンでは ▲▼。
- **ぼかし（ズーム）**：中心から外側へ放射状に流れるぼかし。「量」は外側へ伸ばす割合（20% なら 1.2 倍まで）、「中心 X／Y」は流れの中心（0%＝左端・上端、50%＝中央）。上にあるエフェクト（影や色など）も一緒に流れ、下にあるエフェクトは流れた結果にかかる。流れはキャンバスの範囲で切り取られる（画面でも作業領域にははみ出さない）。
- **一時的にオフ**：左のチェックを外すと設定を残したまま効果だけを外す。
- **強さ**（0〜100%）：すべてのエフェクト共通。エフェクト適用前とのブレンド率（50% なら半分だけ効く）。
- **設定**：名前をクリックすると個別の設定が開く。× で削除。
- すべての操作は Undo／Redo でき、プロジェクトに保存され、書き出しにも反映される。以前のファイルのグロー・ドロップシャドウは読み込み時にこのリストへ変換される（グロー→ドロップシャドウの順）。

### トーンカーブ（エフェクト）

エフェクトの「色の調整」→「トーンカーブ」で、明るさの対応（入力 → 出力、0〜255）を曲線で調整する。

- **調整画面**：追加するとすぐにトーンカーブの画面（ポップアップ）が開く。後から変えるときはエフェクト一覧の「⧉ トーンカーブ」をクリック。画面内の変更はキャンバスにすぐ反映され（プレビュー。背景は暗くしない）、**OK で確定**、キャンセル（または Esc・画面の外をクリック）で元に戻る。追加直後にキャンセルするとトーンカーブ自体も追加されない。画面を開いてから OK までが Undo 1回分。タイトルをドラッグすると画面を移動できる。

- **チャンネル**：RGB（全体）／赤／緑／青。各色のカーブを先にかけ、その後に RGB のカーブをかける。他のチャンネルのカーブは薄く表示される。
- **点の操作**：グラフをクリックすると点を追加してそのままドラッグできる。点はドラッグで移動（左右は隣の点を越えない）、グラフの外へドラッグして離すか Delete で削除（両端の点は削除不可、最大 16 点）。選択中の点は「入力」「出力」に数値でも入力でき、矢印キーで 1（Shift で 10）ずつ動く。PageUp／PageDown で点を切り替え。
- 点の間は単調な 3 次補間（行き過ぎのない滑らかな曲線）。「リセット」で表示中のチャンネルを直線に戻す。

### グラデーション

図形・閉じたパスの「塗り」とテキストの「色」は、種類を **単色／線形グラデーション／放射グラデーション／円錐グラデーション** から選べる。

- **色の帯**：帯をクリックするとその位置に色を追加（その位置の色で作られる）。下の ▲ 付きの四角（色の分岐点）をクリックで選択、左右ドラッグで位置を変更、下へドラッグして離すと削除（2色未満にはできない）。キーボードでは ←→ で 1%（Shift で 10%）移動、Delete で削除。
- **選択中の色**：色（パレット）、不透明度、位置（%）を指定。「色を削除」で削除。
- **角度**（線形・円錐）：画面上の角度（0° = 右向き、90° = 下向き）。線形は中点、円錐は中心のまわりに回る。「反転」で色の並びを逆にする。
- **キャンバス上のハンドル**（選択ツールでオブジェクトを1つ選択中）：丸が始点（放射・円錐では中心）、四角が終点（放射では外周、円錐では開始方向）。ドラッグで調整（Shift で 45° 刻み、ドラッグ1回が Undo 1回分）。
- グラデーションはオブジェクトの拡大縮小・回転に追従し、プロジェクトに保存され、書き出しにも反映される。種類を変えても色は引き継ぐ（位置は初期値に戻る）。単色に戻すと最初の色になる。

### 右クリックメニュー

キャンバス上で右クリックすると、場所に応じたメニューが開く（ブラウザ標準のメニューの代わり）。

- **オブジェクトの上**：カット、コピー、ペースト、複製、削除、最前面へ／最背面へ、グループ化／グループ解除、整列（サブメニュー：左・横中央・右・上・縦中央・下揃え、キャンバスに対して）、パスの編集（パス1つを選択中のとき）。選択外のオブジェクトを右クリックすると、そのオブジェクトだけを選択してから開く。選択中のオブジェクト上では選択を保ったまま開く。
- **何もない所**：ペースト、すべてを選択、グリッドを表示（チェック切り替え）。
- **パスの点（部分選択ツール）**：点の追加、点の削除、角の点に変換、滑らかな点に変換。アンカー上で右クリックするとそのアンカーを選択する（選択済みの複数アンカーはそのまま対象）。輪郭上なら「点の追加」はその位置に、アンカー上ならその次の区間の中央に追加する。

キーボードでは Menu キーまたは Shift+F10 で、選択中のオブジェクト（なければキャンバス）のメニューを開く。メニュー内は ↑↓ で移動、→／Enter でサブメニュー、← で戻る、Esc で閉じる。
テキスト編集中の入力欄では、ブラウザ標準のメニュー（貼り付け・スペルチェック）を使う。
Firefox では Shift+右クリックで常にブラウザ標準のメニューが出る（ブラウザの仕様）。

### ポップアップスライダー

プロパティパネルの数値はすべて同じ形式：数値欄に直接入力するか、右の ▾ を押して縦のスライダーで調整する（ドラッグ（上が大きい値）・トラックのクリック・矢印キー・PageUp/PageDown・Home/End。ドラッグ1回が Undo 1回分。欄外クリックか Esc で閉じる）。
対象：不透明度、線幅（スライダー 0〜50px、入力は 500px まで）、角丸（スライダー上限は短い辺の半分）、頂点数、星の内径比、矢印の軸の太さ・矢じりの長さ、エフェクトの強さと各設定値、画像の明るさ・コントラスト・彩度・色温度・色かぶり補正。
ダイアログ（選択範囲にぼかし・モザイク、書き出し品質）は横長のスライダーのまま。

### フォント

テキストのプロパティの「フォント」を押すと、**この PC にインストールされているフォント**の一覧が開く（各フォント名はそのフォント自体で表示し、横に「あア亜 Aa」の見本）。

- 一覧は「日本語」「欧文」「標準（どの PC でも使える：ゴシック体・明朝体・等幅など）」に分かれる。Windows・Mac・Linux の代表的なフォント（游ゴシック、メイリオ、BIZ UDP ゴシック、ヒラギノ、Arial など）のうち、この PC にあるものだけが出る。
- **この PC のすべてのフォントを表示…**（Chrome／Edge）：ブラウザの許可を求めたうえで、インストール済みのフォントをすべて一覧に追加する。一度許可すると次回からは自動で表示される。ブラウザはフォント名を英語名でしか返さないため、フォントファイルの名前情報（name テーブル）から日本語名を読み取り、日本語名で表示・並べ替え・検索できるようにしている（例：英語名「AR …」のフォントも「AR板体E」で見つかる。マウスを乗せると英語名も表示）。読み取った名前はブラウザに記憶し、ファイルの読み取りは初回だけ。
- 上の検索欄で名前を絞り込める。一覧にない名前を入力して「『…』を使う」で指定することもできる。↑↓ と Enter でも選べる。
- この PC にないフォントが指定されたテキスト（別の PC で作ったファイルなど）は、代わりのフォントで表示され、フォント欄に ⚠ が付く。
- フォントの変更で文字の幅が変わると、テキストの枠も揃えの位置を保って自動で調整される。

### テキストの揃えと大きさの変更

テキストの枠は常に文字の大きさに合わせて自動で調整される。フォントサイズ・フォント・太字／斜体・文字間隔・行間の変更や文字の入力で枠の大きさが変わるとき、揃えの基準点を動かさない：左揃えは左上、中央揃えは上辺の中央、右揃えは右上（回転したテキストでも同じ）。上辺は固定し、下に伸び縮みする。

### 描画後のツール

図形・直線・矢印・テキスト・ペンのパスを作成すると、自動的に選択ツールに戻る（続けて描くときはツールを選び直す）。

### グリッド

表示メニュー（またはステータスバーのチェック）で「グリッドを表示」「グリッドにスナップ」を切り替え、「グリッド設定…」で間隔と色を変更する。
スナップは移動（選択範囲の左上）、拡大縮小、図形・トリミング範囲の描画、ペンのアンカー、テキストの配置、部分選択でのアンカー移動に効く。
グリッドは画面表示のみで、書き出しやプロジェクトファイルには含まれない。設定はブラウザに保存される。

### 整列

複数選択時のプロパティパネル、「変更」メニュー、右クリックメニュー、またはショートカット（Fireworks と同じ）で整列する。

| 整列 | ショートカット |
|---|---|
| 左揃え／横中央（左右）／右揃え | Ctrl+Alt+1／2／3 |
| 上揃え／縦中央（上下）／下揃え | Ctrl+Alt+4／5／6 |
| 均等配置（幅）／均等配置（高さ） | Ctrl+Alt+7／9 |

通常は選択範囲に対して揃え、「キャンバスに対して」をオンにするとキャンバスの中央・端に揃える（1つだけ選択時は常にキャンバス）。
均等配置は、隣り合うオブジェクトの**間隔**を等しくする（左右／上下の端にあるオブジェクトは動かない）。3つ以上の選択が必要。「キャンバスに対して」がオンなら2つ以上で、端のオブジェクトをキャンバスの端に合わせて並べる。macOS では Ctrl+Alt の代わりに ⌘⌥。

### 矢印

図形グループの矢印ツールで、塗り（初期値：黄）と枠線（初期値：黒 4px）を持つブロック形の矢印を描く。尾から先端へドラッグした方向・長さで描画（Shift で 45° 単位）。
プロパティで「軸の太さ」「矢じりの長さ」「先端の角度」を調整でき、向きは「回転」で変更する。以前の線タイプの矢印を含むファイルも引き続き表示・編集できる。

### パネルを隠す（キャンバスを広く）

- レイヤーパネルの左端と、プロパティパネルの上端にある小さなタブ（›／˅）を押すと、そのパネルを隠してキャンバスの作業領域を広げる。隠している間はウィンドウの端にタブ（‹／˄）が残り、押すと元に戻る。
- **F4**（Fireworks と同じ）で両方のパネルをまとめて隠す／表示する。「表示」メニューの「レイヤーパネル」「プロパティパネル」「パネルをすべて隠す／表示」でも切り替えられる。
- 隠す・表示するときは、キャンバスの見えている中心がそのまま保たれる。パネルの表示状態と大きさは次回も引き継ぐ。

### 複数のドキュメント（タブ）

- 「開く」で複数のファイルをまとめて選択でき、それぞれキャンバス上部のタブで開く。タブをクリックで切り替え
- 「新規」も新しいタブで開く。何も編集していない空の「名称未設定」タブは、開いたファイルで置き換える
- タブの ×（または中クリック）で閉じる。未保存の変更があれば確認する。最後のタブを閉じると空の新規ドキュメントになる
- タブバーに .hnb や画像ファイルをドロップすると新しいタブで開く（キャンバスへのドロップは現在のドキュメントへの配置）
- Undo 履歴・選択・表示倍率・スクロール位置・保存先はタブごと。クリップボードは共通（タブ間でコピー＆ペースト可）
- タブ切り替えのキーボードショートカットはなし（Ctrl+Tab などはブラウザが使用するため）

### クリップボード

- **他のアプリの画像を貼り付け**：Windows+Shift+S（切り取り & スケッチ）や他のアプリでコピーした画像を、Ctrl+V（またはメニューの「ペースト」）でキャンバスに貼り付けられる。キャンバスの中央に「クリップボードの画像」として配置される（キャンバスより大きい場合は収まるよう縮小表示。元の画素は保持）。
- HANABI 内でコピーしたオブジェクトは、編集可能なオブジェクトのまま貼り付けられる。後から別のアプリで画像をコピーすると、次の Ctrl+V ではその画像が貼り付けられる（クリップボードには最後にコピーしたものが入る）。
- メニューの「ペースト」でクリップボードの画像を読むとき、ブラウザが許可を求めることがある。テキスト入力欄の中では通常の文字のコピー・貼り付けになる。

### 選択範囲にモザイク

範囲選択ツール（矩形・楕円・投げ縄・多角形）で画像の一部を選び、「画像」メニュー（または範囲選択中にプロパティパネルに出るボタン）の「選択範囲にモザイク…」で、選択した部分だけをモザイクにする。

- 「ブロックの大きさ」（2〜200px、初期値 10px）で粗さを指定する。
- **プレビュー**：「選択範囲にぼかし」「選択範囲にモザイク」のダイアログには「プレビュー」のチェックがあり、オンのときは値を変えるたびにキャンバスで仕上がりを確認できる（背景も暗くしない）。「適用」で確定（Undo 1回分）、キャンセル・Esc では元に戻る。オフにすると「適用」まで画像は変わらない。チェックの状態は次回も引き継ぐ。ブロックは画像の左上を基準に並び、各ブロックをその中の平均色で塗る（透明な画素は平均に含めない）。
- 元画像は変えずに編集情報として保存される。画像のプロパティに「部分加工 N 件（ぼかし・モザイクの内訳）」と表示され、「最後の1件を削除」か Undo で取り消せる。後から画像をリサイズ・トリミングしても範囲は追従する。

### 読み込める画像形式

PNG（Fireworks PNG は統合画像として）、JPEG（.jpg / .jpe / .jpeg）、GIF（アニメーションは1フレーム目）、BMP（.bmp / .dib / .rle）。以前から配置できた WebP も引き続き読み込めます。
形式は拡張子ではなくファイル先頭のバイトで判定し、それ以外（TIFF、PSD など）は理由を表示して読み込みません。

- ファイル → 開く：画像と同じサイズの新規ドキュメント（透明背景）として開く
- ファイル → 画像を配置／キャンバスへドロップ：現在のドキュメントに画像オブジェクトとして追加

## 主要な設計判断

詳細は [`docs/design.md`](docs/design.md)。

- **描画**：ドキュメント全体を1つの SVG で描画し、画面表示と画像書き出しで同じ描画関数を使う。
- **データモデル**：Document → Layer → オブジェクト（図形・パス・テキスト・画像・グループ）。全オブジェクトが「回転付き矩形（box）」を持つ。グループは子をドキュメント座標のまま持ち、変形は子へ同じ変換を適用する。
- **画像**：画素データは不変アセットとして別管理し、ドキュメントは参照だけを持つ。加工は元画像＋パラメータの非破壊パイプライン（切り抜き → リサイズ → 色調整 → 部分ぼかし・部分モザイク）。画像全体のぼかし・グレースケール・セピアはエフェクトで行う。
- **Undo／Redo**：Immer による不変ドキュメントのスナップショット履歴。構造共有と不変アセットにより、画像データを複製しない。ドラッグやスライダー操作は1件にまとめる。
- **保存形式**：`.hnb`（ZIP：`document.json` と `assets/` に元画像を埋め込み）。読み込み時に構造と画像の存在を検証する。旧称時代の `.sparca` ファイルはサポートしない（ファイル選択の対象外）。
- **グラデーション・エフェクト**：グラデーションはオブジェクトの枠に対する正規化座標で保持し、SVG のグラデーション（円錐のみ Canvas で生成した画像）で描く。エフェクトは順序付きリストとして保持し、オブジェクトごとに1つの SVG フィルターへ順につないで描く（焼き込まない）。
- **画像処理**：`src/engine/` に UI 非依存の純粋関数として実装し、Web Worker で実行する。パラメータ変更中は縮小プレビューを先に表示し、操作が止まると原寸で再計算する。補間方式・自動カラー調整のアルゴリズムとパラメータは `docs/design.md` §4 に明記。
- **ファイル操作**：File System Access API が使えるブラウザでは上書き保存、使えない場合はダウンロードで保存する。

## 既知の制約

- 選択ツールのハンドルで画像を拡大縮小した場合の表示はブラウザの補間に従う。補間方式を指定した正確なリサイズは「画像サイズ」ダイアログを使う。
- 画像の部分ぼかし・部分モザイク（選択範囲への加工）を後から個別に編集する UI はなく、「最後の1件を削除」または Undo で取り消す。
- 画像トリミング後に既存の部分ぼかし・部分モザイクの範囲は追従するが、トリミング範囲外になった部分は失われる。
- 回転済みオブジェクトを含むグループを非等倍で拡大縮小すると、子の形は外接矩形ベースの近似になる。
- 部分選択ツールで編集できるのはペンで描いたパスのみ。矩形・楕円などの図形はパラメータ（角丸・頂点数など）で編集する（パスへの変換は未実装）。
- フォントは PC にインストールされたものを使う（ファイルにフォントは埋め込まない）。同じフォントがない PC で開くと、代わりのフォントで表示・書き出しされる。
- SVG 書き出しは未実装（仕様上の拡張候補）。
- 円錐グラデーションは内部で画像（長辺 最大 2048px）として描く。長辺 1024px を超える図形を拡大表示したり、長辺 2048px を超える図形を書き出したりすると、色の境目がやや粗くなることがある。
- 線（枠線）のグラデーションは未対応（単色のみ）。
- エフェクトはグループ全体には付けられない（グループ内の各オブジェクトに付ける）。
- エフェクトは上から順に積み重なるため、後のエフェクトは前のエフェクトが作った部分（影やグローなど）にもかかる。
