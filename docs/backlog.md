## 詳細：エフェクトのライブラリ（2026-11-16 相談）

複数のエフェクトを組み合わせたものを名前を付けて登録し、呼び出して一度に適用する（Fireworks の「スタイル」に近い）。ブラウザ間で持ち運べるようにエクスポート・インポートを付ける。

- **置き場所**：右パネルを上下に分け、上がレイヤー、下がライブラリ。境目のドラッグで高さを変え、高さはブラウザに記憶。見出しのクリックでたためる。それぞれに最小の高さを決め、窓が低いときはライブラリを自動でたたむ。将来、色や柄も登録するならタブで並べる。
- **一覧**：見本（四角や文字にエフェクトを付けた小さな絵）を幅に合わせて並べ、名前はツールチップ。
- **操作**：見本のクリックで選択中のオブジェクトに適用（キャンバス上のオブジェクトへのドラッグ＆ドロップも）。右クリックで名前の変更・削除・エクスポート。見出しに「＋（今のエフェクトを登録）」とインポート／エクスポート。
- **適用**：初期値は今のエフェクトと置き換え、Shift で後ろに追加（案）。ふつうの編集として元に戻せる。
- **保存**：ライブラリはブラウザの中（設定や自動保存と同じ仕組み）。エクスポートは JSON の 1 ファイル（拡張子は例えば `.hnbfx`）に選んだもの／すべて。インポートは同名のとき「上書き／別名で追加／とばす」を選ぶ。読み込むファイルはエフェクトの種類と値の範囲を検証する。
- **作る前に確認すること**（ファイル形式に関わる）：
  1. 登録する範囲：エフェクトだけ（案）か、塗り・線・文字の設定も含めるか
  2. 登録したものを直したとき：コピー方式（案。適用済みのものは変わらない）か、リンク方式（まとめて変わる）か
  3. .hnb のファイルにライブラリを含めるか（案：最初は含めない）

## 詳細：タブレット対応の方針（2026-11-16 相談）

- 別の UI は作らず、今の UI に「タッチ向けの表示」を加える（データ・描画・編集処理は共通）。
- 変えるところ：ボタン・ハンドルを指で押せる大きさに、修飾キー（Shift・Alt・Ctrl）の代わりのボタン、元に戻す／やり直しのボタン、パネルを引き出し式に、2 本指で拡大縮小・移動、2 本指タップで元に戻す、長押しで右クリックのメニュー、ペンと指の使い分け、筆圧。
- 切り替え：OS ではなく入力の種類（`pointer: coarse`、触れたのが指・ペン・マウスのどれか）と画面の幅で自動に判断し、環境設定に「自動（初期値）／マウス向け／タッチ向け」を置いて手動でも選べるようにする。
- 順番の案：1. 2 本指の操作と押しやすい大きさ → 2. 修飾キーの代わりのボタンと引き出し式のパネル → 3. ペンと指の使い分け・筆圧
